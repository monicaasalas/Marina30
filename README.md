# Marina's Birthday Quest v1.0

Proyecto web para GitHub Pages.

## Subir a GitHub
1. Descomprime el ZIP.
2. Sube TODO el contenido a tu repo `Marina30`.
3. Commit changes.
4. Espera a GitHub Pages.
