# Marina's Birthday Quest — versión definitiva

## Publicar en GitHub Pages
1. Descomprime el ZIP.
2. Sube **todo el contenido interior** al repositorio `Marina30`, manteniendo las carpetas.
3. Haz `Commit changes`.
4. Espera a que GitHub Pages termine y abre la web con Ctrl+F5 o en una pestaña privada.

`assets/video/recuerdos.mp4`

## Nota sobre Majo
La lista incluye a Majo entre las opciones, pero su imagen transformada no estaba disponible en los archivos de esta conversación. El juego muestra las 15 imágenes disponibles y mantiene a Majo como posible opción femenina. Cuando tengas su PNG, colócalo en `assets/images/quien/majo.png` y cambia `img:null` por esa ruta en `data/game-data.js`.


## IMPORTANTE PARA SUBIR A GITHUB
No subas este ZIP directamente al repositorio. Descomprímelo y arrastra todos los archivos y carpetas de su interior. El vídeo se abre mediante Google Drive y no se incluye como archivo, para evitar errores de tamaño.
